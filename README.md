## 🚀 Quick Setup

```bash
# 1. Install Python 3.8+, then:
pip install -r requirements.txt

# 2. Setup database
python manage.py migrate

# 3. Create admin user
python manage.py createsuperuser

# 4. Run server
python manage.py runserver
```

Visit: `http://127.0.0.1:8000/`
