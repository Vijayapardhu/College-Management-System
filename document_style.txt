# DOCUMENT STYLE GUIDE for Project Docs

Font:
  - Headings: Times-Bold, 18pt
  - Subheadings: Times-Bold, 14pt
  - Body text: Times-Roman, 12pt
  - Line spacing: 1.5x
  - Alignment: Justified
  - Margins: 1 inch on all sides
  - Page size: A4

Sections Order:
  1. Title Page (Centered, uppercase project title, subtitle, team details, guide)
  2. Certificate
  3. Declaration
  4. Acknowledgment
  5. Abstract
  6. Index/Table of Contents
  7. Main Chapters
      - Introduction
      - Requirements & Analysis
      - System Design
      - Implementation Issues
      - Testing
      - Coding
      - Output Screens
      - Conclusion
      - Bibliography

Headings should be uppercase and bold.
Subheadings should be bold with section numbers (e.g., 3.2 System Architecture).
Body text should be left-justified paragraphs.
Each major section should start on a new page.
Add page numbers at bottom center.
