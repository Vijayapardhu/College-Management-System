     STUDENT STRUCTURE REDESIGN - COMPLETE!


 NEW MODELS ADDED:

1. AcademicYear
    Represents year levels (1st, 2nd, 3rd, 4th, 5th Year)
    Each year has a number and name

2. Section
    Represents sections (A, B, C, D, etc.)
    Each section has capacity (default 60)

3. ClassGroup
    Combines: Department + Year + Section + Session
    Example: CSE - 2nd Year - Section A - C23
    Can assign class teacher

4. Updated Session Model:
    Added session_name field (e.g., 'C23', 'C24')
    C23 = 2023-2026 (3-year program)
    C24 = 2024-2027 (3-year program)
    More user-friendly than dates!

5. Updated Student Model:
    Added department field
    Added academic_year field (1st, 2nd, 3rd, 4th year)
    Added section field (A, B, C, D)
    Added class_group field (links to specific class)

 STRUCTURE HIERARCHY:

Department
   Course/Program
       Session (C23, C24, C25...)
           Academic Year (1st, 2nd, 3rd, 4th)
               Section (A, B, C, D)
                   ClassGroup
                       Students

    Department dropdown
