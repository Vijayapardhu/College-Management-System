## 🔧 **HOW TO USE THESE FEATURES**

- Pending
- Approved
- Completed
- Rejected

### **Step 4: Download/View Results**
Once approved, download certificates/receipts/documents

3. **Create Online Exam:**
   Staff Login → ONLINE EXAMINATION → Create Online Exam → Add Questions → Publish

4. **Add Internship:**
   Student Login → INTERNSHIPS → Add Internship → Fill Details → Upload Documents → Submit

5. **Report Ragging:**
   Student Login → SAFETY → Report Ragging → Fill Details → Upload Evidence → Submit

6. **Add Publication:**
